# File Toolkit: офлайн конвертор файлів + архіватор

Десктопна програма для Windows на Python. Працює повністю офлайн,
файли нікуди не відправляються.

## Технології
- Python 3.11+, інтерфейс на customtkinter (темна тема).
- Зображення: Pillow. ZIP/TAR: стандартна бібліотека. 7z: py7zr.
- Збірка в один .exe: PyInstaller.
- Залежності записувати в requirements.txt.

## Структура
- main.py: запуск програми
- app/ui.py: вікно та вкладки
- app/converter.py: логіка конвертації
- app/data_converter.py: логіка конвертації даних (JSON, CSV, TXT)
- app/archive.py: логіка архівів
- tests/: прості тести логіки

## Правила
- Інтерфейс українською.
- Логіка (converter, archive) окремо від інтерфейсу, щоб її можна було тестувати.
- Обробляти помилки: пошкоджений файл, невідомий формат, немає місця, файл зайнятий.
- Інтерфейс не повинен зависати на великих файлах: важку роботу робити в окремому потоці.
- Кожен етап робити окремо, не змінювати зайвого.
- Не використовувати нічого, що потребує інтернету під час роботи програми.

## Git
- Після кожного завершеного й перевіреного етапу: git add, git commit
  з коротким описом англійською (наказовий спосіб), потім git push у main.
- Не комітити нічого, що не працює.
- У .gitignore: __pycache__/, build/, dist/, venv/, *.spec

## Етапи
1. Каркас: venv, requirements.txt, вікно з вкладками «Конвертер» і «Архіватор», вибір файлів.
2. Конвертація зображень (PNG, JPG, WebP, BMP), якість і розмір.
3. Конвертація даних: JSON, CSV, TXT.
4. Створення ZIP з обраних файлів і папок.
5. Розпаковка ZIP, TAR, 7z з вибором папки призначення.
6. Збірка в .exe (PyInstaller), перевірка запуску на чистому ПК.
7. README зі скриншотами, випуск на GitHub Releases.

(оновлювати після кожного етапу)

- Етап 1 — виконано (25.10.2026): venv і requirements.txt (customtkinter 5.2.2),
  .gitignore, каркас main.py + app/ui.py з вкладками «Конвертер» і «Архіватор»,
  вибір файлів і папок зі списком та лічильником, заглушки app/converter.py
  і app/archive.py, тести каркасу на unittest (усі проходять).

- Етап 2a — виконано (25.10.2026): додано Pillow 13.0.0 у requirements.txt,
  повна логіка app/converter.py: PNG/JPG/WebP/BMP в обидва боки, режим
  «Як у вихідному», якість (JPG/WebP) і рівень стиснення (PNG), зміна розміру
  (довша сторона, відсоток, точний розмір, без збільшення), підкладка для
  прозорості у JPG/BMP, EXIF-орієнтація та збереження EXIF/ICC, атомарний
  запис без перезапису оригіналів, колізії імен, перевірка місця на диску,
  прогрес і скасування пакета. 44 тести в tests/test_converter.py,
  разом з тестами каркасу — 48, усі проходять.

- Етап 2b — виконано (25.10.2026): інтерфейс конвертера в app/ui.py —
  блок налаштувань (формат, якість/стиснення з підказками, режим розміру
  з полями довшої сторони/відсотка/точного розміру, підкладка для
  прозорості, папка призначення з кнопками «Оглянути…» і «Скинути»),
  кнопки «Конвертувати», «Скасувати», «Відкрити папку», прогрес-бар із
  назвою поточного файлу, робота у фоновому потоці через queue і
  self.after, блокування елементів під час роботи, перевірка налаштувань
  перед стартом, підсвітка непідтримуваних файлів у списку та підсумок
  з переліком помилок. Вікно підганяється під вміст і межі екрана.
  Тести: 48, усі проходять; перевірено вручну пакет, скасування,
  пошкоджений файл і збереження поруч з оригіналами.

- Етап 3a — виконано (25.10.2026): новий модуль app/data_converter.py —
  конвертація JSON, CSV і TXT у всіх напрямках через спільне проміжне
  подання Table/JsonValue: авто-визначення кодування (BOM, UTF-8,
  Windows-1251, latin-1) і роздільника CSV, заголовки з дедуплікацією,
  вирівнювання різноширинних рядків, визначення типів для CSV/TXT→JSON
  (вимкнено за замовчуванням, «007» і телефони лишаються текстом),
  форматування JSON (відступ, сортування ключів), вирівняний і
  роздільниковий TXT, кодування/BOM/переноси результату, ліміти
  MAX_INPUT_BYTES і MAX_ROWS, атомарний запис без перезапису оригіналів,
  колізії імен, перевірка місця, прогрес і скасування пакета (зокрема
  всередині великого файлу). 39 тестів у tests/test_data_converter.py,
  разом з попередніми — 87, усі проходять. Вимогу до Python уточнено
  на 3.11+. Інтерфейс вкладки «Дані» — на етапі 3b.
